# Isfakur Rahman — Personal Portfolio

A responsive personal portfolio starter built with **HTML5 and CSS3 only**.

## Files
- `index.html` — page structure and content
- `style.css` — responsive layout, theme, and visual styling

## Run locally
1. Extract the ZIP file.
2. Open the `isfakur-portfolio` folder in Visual Studio Code.
3. Open `index.html` in your browser (or use the Live Server extension).

## Personalize before publishing
1. Replace `your-email@example.com` in `index.html` with your real public contact email.
2. Replace the GitHub and LinkedIn profile links with your own URLs.
3. Review the education details and make sure they are accurate.
4. Replace the sample project cards with your actual projects and repository links.
5. Add your own profile photo if you want one. The current hero uses a CSS monogram, so no image is required.

## Publish with GitHub Pages
1. Create a public GitHub repository, for example `my-portfolio`.
2. Upload `index.html`, `style.css`, and this README.
3. Open **Settings → Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**.
5. Select branch `main` and folder `/ (root)`, then Save.

This starter intentionally uses only HTML and CSS. The navigation links work through in-page anchors; the email link opens the visitor's email app. A working contact form would require a backend or form service.
